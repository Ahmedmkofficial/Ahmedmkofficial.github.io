# Phantom Terminal Portfolio

A responsive, animated GitHub Pages portfolio built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Features
- Matrix-style ambient animation and animated terminal prompt
- Neon-green futuristic styling, orbital hero visual, and scroll reveals
- Responsive layout and reduced-motion support
- Simulated terminal with a small allowlist of harmless commands
- Adera listed as under evaluation; SARA shown as a contribution without a private-repository link
- No backend, trackers, or external API calls

## Publish with GitHub Pages
1. Create a **new public repository** named exactly `Ahmedmkofficial.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder to the repository root.
3. Commit the files to `main`.
4. Open the new repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main`, folder `/ (root)`, and click **Save**.
7. After deployment completes, visit `https://Ahmedmkofficial.github.io`.

This is a separate website repository. It does not modify Adera, SARA, or any existing project repository.

## Personalization
- Edit the copy and links in `index.html`.
- Adjust colors and animation in `style.css`.
- Change the typing phrases and safe terminal commands in `script.js`.
- Keep project descriptions accurate; do not add private links or claims you cannot verify.

## Local preview
Open `index.html` in a browser, or run `python3 -m http.server 8080` in this folder and visit `http://localhost:8080`.
